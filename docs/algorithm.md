# 算法

WGC 在连接屏幕的 NVIDIA 设备上取得原始分辨率纹理；HDR 使用 FP16 scRGB。不创建降分辨率或横竖模糊中间纹理。

普通灯区的宽度由沿边灯珠间距划分，相邻普通灯区不重叠。深度单位为屏幕高度百分比，垂直边也使用相同像素深度。设深度 R，像素中心到屏幕边缘距离 d，令 q=d²/R²，最终权重为 exp(-2q) × (1-q)²（q<1），q≥1 时为零。高斯部分 sigma=R/2，乘以平滑窗使边界权重及一阶导数都归零。宽度方向等权，中心在屏幕边缘。

四颗角灯以屏幕角点为中心，在半径 R 的四分之一圆内令 q=(dx²+dy²)/R²，使用相同的 exp(-2q) × (1-q)²，圆外不参与。角灯与边灯可能重叠。每灯除以自身有效权重之和。

每灯一个 256 线程组，完整遍历区域像素，在线性颜色空间累加、归约。像素距离权重表在深度、尺寸或采集会话重建时生成；两个一维高斯权重相乘得到径向高斯，再按径向距离乘平滑窗；不把两个一维平滑窗相乘，以保持圆对称。

结果是 45 个 float4（720 字节），CPU 读取后进行相邻灯混合、色彩响应校正和 USB 输出。原分辨率采集缓冲仍占显存，不使用中间 RT 并非零显存开销。

成本随深度、分辨率、重叠区域增大。数值测试覆盖常色、渐变、稀疏亮点、SDR/HDR 和 4K；数值一致性不能替代动态画面与高 GPU 负载观感验收。

平滑窗会让外圈比旧版本更轻，不再在边界留下 13.5% 的阶跃。最终仍除以权重总和，纯色输入不会因此变暗。不增加中间纹理。
